# KORA ATELIER — Contemporary Clothing Storefront Showcase

A concept fashion & contemporary streetwear e-commerce storefront built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

## Features
- Editorial homepage with Capsule 04 hero, category strip, featured drop grid, and lookbook banner
- Shop page with category filter, size filter (`XS`–`XL`), and price sorting
- Product cards with hover studio view swap, color swatches, and quick-add size bar
- Product detail page with interactive color/size selectors, measurement size guide modal, and WhatsApp order option
- Slide-over Shopping Bag drawer with quantity controls and free-shipping progress indicator

## Run Locally
```bash
npm install
npm run dev
```
